# F2: 하단 탭 5개 + 홈 화면 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (인라인, 사용자 선호). Steps use checkbox (`- [ ]`) syntax.

**Goal:** 탭을 5개(홈/탐색/랭킹/신작/프로필)로 확장하고, 웹 홈과 동등한 데이터 섹션을 가진 모바일 홈 화면을 구현한다. (스펙 F2)

**Architecture:** 스타일은 **StyleSheet + 디자인 토큰**(`src/theme/tokens.ts` — 웹 Tailwind 값 미러). 데이터는 전부 @aod/shared 훅. 스펙: `docs/superpowers/specs/2026-07-11-mobile-app-monorepo-design.md`

**스타일 전략 결정 (2026-07-13, F1에서 연기된 숙제):** NativeWind **보류** — v5는 pre-release(프로덕션 비권장 명시), v4(안정)는 Tailwind 3.4 기반 + 템플릿의 Reanimated 4.5와 충돌 위험. 웹 Tailwind 클래스의 "의미"(색·간격·타이포)는 토큰 모듈로 이식한다. **v5 안정화 시 도입 재검토.**

**Tech Stack:** Expo Router NativeTabs(템플릿 유지), @aod/shared hooks, expo-image, FlatList(horizontal)

## Global Constraints

- 브랜치: `feature/f1-expo-bootstrap`에 이어서 커밋 (F2 완료 후 함께 PR — 사용자 결정으로 머지 지연 중).
- 웹·shared 기존 파일 무수정 (F0/F1과 동일).
- 홈의 데이터 소스·캐시 키는 웹 home-page.tsx와 동일: `["home-all-rankings"]`(페이지 전용 키, 화면에 남김) + `useRecentReviewedWorks` + `useRecentReleases` + `useUpcomingReleases`.
- 색·간격은 tokens.ts만 사용 (하드코딩 hex 금지 — #855BFF 등 웹 값을 토큰으로 승격).
- 탭 아이콘: 홈·탐색은 템플릿 png 재사용, 랭킹·신작·프로필은 임시로 기존 png 재사용 + **정식 아이콘은 F5(스토어 에셋)에서** — 계획에 명시된 의도적 부채.
- 게이트: `pnpm --filter @aod/mobile typecheck && test` + `expo export` + 에뮬레이터 스크린샷 검증.

### Task 3: 홈 화면

**Files:**
- Rewrite: `apps/mobile/src/app/(tabs)/index.tsx` (템플릿 웰컴 → AOD 홈)

**구성 (웹 home-page.tsx 섹션 미러 — 구현 전 웹 파일 전체 읽고 확정):**
1. 상단 검색바 (탭하면 F3 검색 화면 예정 — 지금은 비활성 placeholder 입력)
2. 도메인 랭킹 섹션 (`useQuery(["home-all-rankings"], rankingApi.getAllRankings)` — 웹과 동일 키, 도메인별 상위 3, 좌우 스와이프; 웹의 5초 자동 슬라이드는 모바일 UX상 수동 스와이프로 대체 — 의도적 차이)
3. 최근 리뷰 작품 캐러셀 (`useRecentReviewedWorks({ size: 10 })`)
4. 신작 캐러셀 (`useRecentReleases`) / 출시 예정 캐러셀 (`useUpcomingReleases`)
5. 작품 탭 → `/work/[id]`는 F3 — 지금은 no-op 또는 준비중 알림

**Steps:**
- [ ] 웹 home-page.tsx 전체 읽기 → 섹션·파라미터 확정 (위 목록과 다르면 웹 기준)

- [ ] typecheck + test + `expo export` 그린
