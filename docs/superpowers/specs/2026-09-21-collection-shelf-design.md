# 컬렉션 책장 — 설계 (1단계: 상세 화면 · 2단계: 내 책장 · 발견 카드 · 담기 목록)

작성일: 2026-09-21 · 대상: `apps/web`, `packages/shared` · 목업: `mockups/collection-shelf-mockup.html`

## 목표

컬렉션 상세를 "포스터 콜라주 + 행 리스트"에서 **책장**으로 바꾼다. 작품은 책등으로 꽂히고,
꽂고·빼고·메모하고·옮기는 일이 전부 이 화면에서 끝난다. 수집을 자극하는 것은 점수·배지가 아니라
물성이다 — 빈 칸, 꽂히는 모션, 표지가 세워지는 보상.

## 목업과 달라지는 점 (조사 결과)

1. **컬렉션은 단일 도메인이다** (`addItem` 도메인 불일치 400). 목업의 섞어 꽂기는 불가능하다.
   → 도메인 규격은 유지하되, 같은 도메인 안에서 `contentId` 로 결정되는 두께·높이 변주를 넣어
   선반 윤곽을 살린다 (같은 작품은 언제나 같은 책등).
2. **상세 GET 은 조회수를 +1 한다.** 목록에서 컬렉션마다 상세를 불러 책등을 그릴 수 없다.
   → 목록에서 책등을 그리려면 백엔드가 요약 응답에 책등을 실어 줘야 한다 (아래 "2단계-a").

## 범위

**포함:** `/collections/:id` 상세 화면, 소유자용 인라인 편집(꽂기·빼기·메모·옮기기), 공용 shared 훅.

**2단계로 추가:** 내 컬렉션 탭 = 내 책장, 발견 카드·담기 목록의 미니 책장 (아래 절). **제외:** `/collections/:id/edit`(그대로 — 제목·틴트·공개 범위·일괄 정리는 여기서), 백엔드.

## 화면 구성

```
lg+                                                    <lg
[뒤로]                                                 [←] 제목            [편집][공유]
게임 컬렉션                                            게임 컬렉션
제목                       [좋아요][공유][편집]        제목 / 소개 / 큐레이터
소개 / 큐레이터 · N작품 · 업데이트 · 조회              [책장|목록]        [작품 꽂기]
[책장|목록]                          [작품 꽂기]*      ┌ 책장 (폭에 맞춰 여러 단) ┐
┌ 책장 (1fr) ─────────┐ ┌ 옆 패널 320px sticky ┐       └─────────────────────────┘
│ 책등 · 표지+메모 · 빈 칸* │ │ 뽑아든 작품 | 작품 꽂기* │   (선택 시) 하단 카드: 뽑아든 작품
└─────────────────────┘ └──────────────────────┘       [좋아요 바]
* = 소유자만
```

기존 콜라주 히어로는 없앤다 — 책장이 히어로다.

## 책장 규칙

- **책등**: 세로쓰기 제목 + 도메인 아이콘. 질감 = `posterUrl` 가운데 조각(어둡게 덮음). 이미지가 없거나 깨지면 틴트 단색.
- **규격**(배율 1): 영화 24×178 · 시리즈 40×178 · 게임 22×166 · 웹툰 27×152 · 웹소설 36×188.
  변주: 두께 −3…+8px, 높이 0…−9px — `contentId` 해시로 결정.
- **표지 세우기**: 코멘트가 있는 작품 중 **앞에서 3개**는 표지(WorkThumb 와 같은 cover/contain 규칙) + 손글씨 메모 카드. 나머지 코멘트는 옆 패널에서 보인다. 표지와 메모는 한 칸이라 줄바꿈에도 붙어 다닌다.
- **빈 칸**: 소유자에게만, 끝에 3개. 첫 칸은 누를 수 있고(작품 꽂기) 은은하게 숨 쉰다. 방문자에게는 빈 칸이 없다 — 누를 수 없는 "+" 는 거짓말이다.
- **선반 판**: 행 높이만큼 반복되는 배경. 폭이 바뀌어 단 수가 달라져도 JS 없이 따라온다.
- **뒷벽**: 컬렉션 `tint`.

## 상호작용 (사용감)

| 하는 일 | 방법 | 반응 |
|---|---|---|
| 훑어보기 | 마우스를 책등 위로 | 책등이 12px 올라오고 전체 제목 말풍선 (세로 제목이 잘려도 읽힌다) |
| 뽑아보기 | 책등 클릭/탭, Enter | 22px 뽑히고 옆 패널(모바일: 하단 카드)에 표지·메타·메모·`작품 보기` |
| 도로 꽂기 | 같은 책등 다시, Esc, 모바일 카드의 × | 선택 해제 |
| 키보드 | 책장은 Tab 한 칸(roving tabindex). ←/→ 이동, Home/End | 100권이어도 Tab 지옥이 없다 |
| **꽂기**(소유자) | 빈 칸 · `작품 꽂기` → 옆 패널이 "작품 꽂기"로 바뀜 (모바일: 바텀시트) | 검색(250ms 디바운스, 컬렉션 도메인 한정). 검색어가 없으면 그 도메인 작품 목록. 행의 `꽂기` → 책등이 위에서 떨어져 들어오고 옆 책이 밀린다. **패널은 닫히지 않는다** — 연달아 꽂는다. 이미 꽂힌 작품은 `꽂힘` |
| **빼기**(소유자) | 뽑아든 작품 → `책장에서 빼기` | 확인 창 없이 즉시. 토스트 `뺐어요 · 되돌리기`(5초) — 되돌리면 같은 자리·같은 메모로 복원 |
| **메모**(소유자) | 뽑아든 작품의 메모 칸 (200자) | 포커스를 떼거나 Ctrl/⌘+Enter 로 저장, 낙관적 반영. 앞 3개 안에 들면 책등이 그 자리에서 표지로 바뀐다. 안내문: "메모를 남기면 표지가 보이게 세워져요 (앞에서 3개)" |
| **옮기기**(소유자) | 뽑아든 작품의 ◀ ▶ | 한 칸씩, 낙관적 반영. 선택은 따라간다. 여러 개를 크게 옮기는 일은 편집 화면 |
| 목록으로 보기 | `책장 | 목록` | 기존 행 리스트(평점·메타가 한눈에). 선택은 localStorage 에 기억 |

- 첫 진입: lg+ 는 첫 작품이 뽑혀 있다(옆 패널이 비어 보이지 않게). <lg 는 아무것도 안 뽑혀 있다(하단 카드가 화면을 가리지 않게).
- 빈 컬렉션: 소유자는 빈 칸 3개 + 옆 패널이 "작품 꽂기"로 열린 채. 방문자는 기존 빈 상태.
- `prefers-reduced-motion`: 뽑힘·꽂힘·숨쉬기 애니메이션 없음(상태 변화는 그대로).
- 실패: 낙관적 변경은 되돌리고 토스트. 401 은 로그인 안내 문구(기존 관례).

## 2단계-a: 내 책장 (내 컬렉션 탭)

컬렉션 하나가 선반 한 단이다. 뒷벽은 그 컬렉션의 tint, 선반 앞턱의 이름표에 제목·도메인·작품 수·공개 범위.
단 끝에는 빈 칸 하나("더 꽂을 수 있다"), 책장 맨 아래는 늘 빈 선반("새 책장 만들기").
단 전체가 그 컬렉션 상세로 가는 링크다. 책등은 누를 수 없다(작은 책등 `MiniSpine`) - 뽑아 보는 일은 상세에서.

- **백엔드** (`-AOD-All-of-Dopamine-back`, 브랜치 `feature/collection-spines`): `CollectionSummaryDTO.spines`
  = 상위 20권의 `{contentId, title, posterUrl}` (position 순, 조회 시 파생). 도메인은 싣지 않는다(단일 도메인).
  `findCoverPosters` 를 `findSpines` 로 바꾸고 `coverPosters` 는 거기서 파생(포스터 있는 앞 3개) - 목록 요청당
  윈도 쿼리는 그대로 1번. 하위 호환: 기존 필드는 그대로, 새 필드만 추가.
- **프론트**: `CollectionSummary.spines?` 는 선택 필드. 내 컬렉션 응답에 `spines` 가 하나도 없으면(구 백엔드)
  기존 카드 그리드로 떨어진다 - 프론트가 먼저 배포돼도 깨지지 않는다.
- `components/shelf/Bookcase.tsx` · `MiniSpine.tsx`, `index.css` 의 `.shelf-bookcase` · `.shelf-tier` · `.shelf-tier-plank`.
- 20권을 넘는 컬렉션은 `+N` 으로 나머지를 알린다.

## 2단계-b: 발견 카드 · 담기 목록의 미니 책장

- **발견 카드** (`CollectionCard`): 포스터 3장 콜라주 자리에 선반 한 토막(`ShelfScene`) - 같은 `spines` 를 쓴다.
  카드 폭은 열 수에 따라 크게 달라지므로(16:9 라 높이도 같이) 책등을 **장면 높이에 비례**시킨다
  (컨테이너 쿼리 단위 `cqh`, `MiniSpine` 이 단위 없는 `--wn`/`--hn` 을 같이 싣는다). 폭을 넘는 책등은 잘린 채로 둔다 -
  선반이 프레임 밖으로 이어지는 것처럼 보인다. `spines` 가 없으면 기존 콜라주.
- **담기 목록** (`AddToCollectionMenu` 의 PickList - 팝오버·바텀시트 공용): 행 썸네일이 미니 책장(`ShelfStrip`).
  끝 자리의 점선 빈 칸이 "여기 꽂힌다"를 보여 주고, 담으면 그 자리에 액센트 색 책등이 떨어져 들어온다.
  백엔드: `MyCollectionSummaryDTO.spines` (같은 `findSpines`). `spines` 가 없으면 기존 틴트 스와치.
- 컬렉션 상세의 "내 컬렉션에 담기"(방문자)도 같은 PickList 라 함께 바뀐다.
